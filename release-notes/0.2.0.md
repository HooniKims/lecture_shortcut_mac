Cue 0.2.0 · 개발 프리뷰

• 원하는 브라우저 탭이나 앱 창에서 ⌘ + ⇧ + 0을 눌러 바로 등록할 수 있습니다.
• 등록할 화면을 탭·창·앱으로 나누어 찾고, 웹페이지 주소로도 검색할 수 있습니다.
• 밝은 Paper 테마와 어두운 Studio 테마를 선택할 수 있습니다.
• 상단 메뉴 막대 아이콘을 단색으로 정리하고, 업데이트 확인 메뉴를 추가했습니다.
• 새 버전이 있으면 달라진 점을 안내합니다. 업데이트하거나 취소할 수 있고, 설치 후 자동 재시작 여부도 선택할 수 있습니다.
• 중복 등록과 단축키 충돌, 빠른 연속 입력 처리를 개선했습니다.

시험 사용 버전입니다. 개별 탭 동작은 Chrome과 Safari에서 검증했으며, 실제 듀얼 모니터 환경은 추가 확인이 필요합니다.
