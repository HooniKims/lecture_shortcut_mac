# Cue

Cue는 강의에 쓸 화면을 단축키로 불러오는 Mac 앱입니다. 발표 자료에서 웹페이지로, 다시 다른 프로그램으로 넘어갈 때마다 창을 찾는 수고를 덜어 줍니다.

현재는 **0.2.0 개발 프리뷰**입니다. Apple Silicon(M1·M2·M3·M4 등) Mac과 macOS 13 이상에서 사용합니다. Windows용과 Intel Mac용 설치파일은 아직 제공하지 않습니다.

## 설치하기

[설치파일 배포 페이지](https://github.com/HooniKims/lecture_shortcut_mac/releases)에서 `.dmg` 파일을 받습니다. 파일이 보이지 않으면 아직 공개 배포 전입니다.

1. 받은 `.dmg` 파일을 엽니다.
2. Cue를 **응용 프로그램** 폴더로 옮깁니다.
3. 응용 프로그램 폴더에서 Cue를 실행합니다.

개발 도구나 브라우저 확장 프로그램은 따로 설치하지 않아도 됩니다. DMG 안에서 바로 실행하는 대신 응용 프로그램 폴더로 옮겨 주세요. 앱 안에서 업데이트할 때 필요합니다.

처음 실행할 때 macOS가 개발자를 확인할 수 없다는 경고를 표시할 수 있습니다. 본인이 받은 Cue 파일이 맞는지 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**에서 실행을 허용합니다. 이 개발 프리뷰는 Apple 공증을 받지 않았습니다.

## 처음 실행하면 권한을 허용해 주세요

다른 프로그램의 창을 앞으로 가져오고 옮길 수 있도록 Cue에 권한을 허용해 주세요.

- **손쉬운 사용:** 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Cue를 켭니다.
- **자동화:** 브라우저 탭을 등록할 때 브라우저 제어 요청이 나오면 허용합니다.

허용했는데 창이 움직이지 않으면 메뉴 막대의 Cue에서 **Cue 종료**를 선택한 뒤 다시 실행해 보세요. 창의 닫기 버튼만 누르면 앱은 계속 실행됩니다.

## 화면 하나 등록해 보기

1. 강의에 사용할 앱이나 웹페이지를 먼저 엽니다.
2. Cue에서 **화면 등록**을 누릅니다.
3. 목록에서 앱, 특정 창 또는 브라우저 탭을 선택합니다.
4. 표시 이름과 단축키를 정하고 **등록하기**를 누릅니다.
5. 등록한 단축키를 눌러 화면이 앞으로 나오는지 확인합니다.

표시 이름은 창이나 탭의 제목으로 채워집니다. “실습 페이지”, “강의 자료”처럼 알아보기 쉬운 이름으로 바꿔도 원래 창의 제목은 바뀌지 않습니다.

단축키 입력칸을 선택한 뒤 원하는 키를 함께 누르면 됩니다. 예를 들어 `⌘ + ⇧ + 1`은 Command, Shift, 숫자 1을 함께 누르는 조합입니다. 보조키와 함께 누를 실행키는 다른 색으로 표시합니다.

화면이 이미 맨 앞에 있다면 같은 단축키를 한 번 더 눌러 최소화하세요. 다시 누르면 화면을 불러옵니다. 단축키 대신 목록의 화면을 선택하고 **화면 띄우기**를 눌러도 됩니다.

## 보고 있는 화면 바로 등록하기

앱이나 탭이 많다면 목록에서 찾지 않아도 됩니다.

1. 등록할 브라우저 탭이나 앱 창을 앞으로 띄웁니다.
2. **`⌘ + ⇧ + 0`**을 누릅니다.
3. 작은 **빠른 등록** 창에서 제목과 주소를 확인합니다. 표시 이름과 추천 단축키는 바꿀 수 있습니다.
4. **Enter**를 누르면 저장하고 원래 창으로 돌아갑니다. **Esc**를 누르면 취소합니다.

등록만으로 원래 창이 움직이거나 탭이 분리되지는 않습니다. 나중에 호출 단축키를 눌렀을 때 선택한 방식으로 이동합니다. 이미 등록된 화면과 중복 단축키는 안내하며, 탭을 읽지 못하면 앱 전체로 대신 등록하지 않습니다.

목록에서 고를 때는 **브라우저 탭 · 창 · 앱** 필터를 사용하세요. 탭 제목 아래에 사이트 주소도 표시합니다.

## 자주 쓰는 단축키

| 기본 단축키 | 하는 일 |
| --- | --- |
| `⌘ + ⇧ + 1`부터 `⌘ + ⇧ + 9` | 화면을 등록할 때 제안하는 단축키 |
| `⌘ + ⇧ + 0` | 현재 앞에 있는 화면을 빠르게 등록 |
| `⌘ + ⇧ + Space` | 발표자 패널 표시·숨기기 |
| `⌘ + ⇧ + Return` | 대기 중인 화면을 청중 모니터로 보내기 |

화면별 단축키는 목록에서 해당 화면을 선택해 바꾸세요. 패널을 켜고 끄는 단축키는 **환경 설정**에서 바꿉니다. 다른 단축키와 겹치면 저장할 때 안내합니다.

## 모니터와 Zoom 화면 공유

**환경 설정 → 청중에게 보여줄 모니터**에서 강의 화면을 띄울 모니터를 선택합니다. Zoom에서 전체 화면을 공유한다면, Zoom에서 공유한 모니터와 같은 모니터를 선택해 주세요. Cue가 Zoom의 공유 설정을 직접 바꾸지는 않습니다.

모니터가 두 대라면 **대기 모드**를 사용해 보세요. 화면을 원래 모니터에 띄워 준비하고, 준비가 끝나면 청중 모니터로 보냅니다. 필요할 때만 켜서 사용하세요. 모니터가 한 대면 대기 모드는 사용할 수 없습니다.

창을 옮길 때 기존 크기를 유지합니다. 크기는 옮긴 뒤 직접 조절하면 됩니다.

## 브라우저 탭 사용하기

탭을 등록하면 **이 탭만 새 창으로 이동**하거나 **브라우저 창 전체 이동** 중에서 고릅니다. 다른 탭을 함께 보여주고 싶지 않을 때는 탭만 옮기는 방식을 사용하세요.

탭 기능은 Chrome과 Safari를 우선 지원합니다. Edge, Brave, Vivaldi, Opera, Arc에도 탭 연결 기능을 넣었지만, 각 브라우저에서 추가 확인이 필요합니다. Firefox처럼 탭 제어를 지원하지 않는 브라우저는 목록에서 앱이나 창을 직접 선택해 등록하세요. 빠른 등록에서는 지원되지 않는 탭을 앱으로 바꾸지 않습니다.

탭 분리가 되지 않으면 이동 방식을 **브라우저 창 전체 이동**으로 바꿔 보세요. 닫힌 앱이나 저장된 웹페이지는 다시 열 수 있지만, 문서 프로그램에서 닫아 버린 개별 문서까지 복원하지는 않습니다.

## 강의별 목록과 발표자 패널

왼쪽 **강의 프리셋** 옆의 `+`를 누르고 목록에 이름을 붙여 저장하세요. 강의마다 필요한 목록을 따로 보관해 두면 편합니다. 프리셋을 불러오면 그 목록으로 현재 목록을 바꿉니다.

**발표자 패널**에서 등록한 이름과 단축키를 한눈에 확인하세요. 제목 부분을 드래그하면 다른 모니터로 옮겨집니다. 필요할 때만 패널을 켜 두면 됩니다. 패널에서 화면을 눌러 바로 불러와도 됩니다.

환경 설정의 **재시작 후에도 등록 유지**를 켜면 Cue를 다시 열어도 목록이 남습니다. 끄면 다음 실행 때 현재 목록은 비워지지만, 직접 저장한 프리셋과 설정은 남습니다.

밝은 화면이 편하면 **B · Paper**, 어두운 화면이 편하면 **C · Studio**를 선택하고 저장합니다. 메인 창과 발표자 패널에 함께 적용됩니다.

## 업데이트하기

**환경 설정 → 앱 업데이트 → 업데이트 확인**을 누릅니다. 새 버전이 있으면 변경 내용을 읽고 **업데이트 설치**를 선택합니다. 설치가 끝나면 **Cue 다시 시작**을 눌러 적용합니다.

**새 버전 자동 확인**을 켜 두면 앱을 열 때 하루 한 번 확인합니다. 새 버전이 있어도 강의 중 앱이 자동으로 종료되거나 다시 시작되지는 않습니다. 설치는 강의를 마친 뒤 진행해 주세요.

등록 목록과 프리셋, 설정은 앱과 별도로 저장합니다. 업데이트 직전에 설정도 백업합니다. 다만 **재시작 후에도 등록 유지**를 꺼 두었다면 재시작 때 현재 목록은 비워집니다.

공개된 업데이트가 없거나 배포 정보를 가져오지 못하면 그 이유를 화면에 안내합니다. 인터넷 연결이 끊겼거나 파일 검증에 실패한 경우에는 다시 확인해 주세요. 파일을 검증하기 전에는 기존 앱을 교체하지 않습니다.

업데이트 기능이 없는 이전 Cue를 쓰고 있다면, 이 기능이 포함된 설치파일을 한 번 직접 설치해야 합니다.

## 알아두세요

현재는 시험 사용 버전입니다. 실제 듀얼 모니터와 Zoom 공유 환경에서는 더 확인해야 할 부분이 남아 있습니다. 강의 전에 화면이 잘 전환되는지 미리 점검해 주세요. 업데이트 후 macOS 권한을 다시 허용해야 하는 경우도 있습니다.

등록한 창 제목과 웹페이지 주소는 Mac에 저장하며 업데이트 서버로 보내지 않습니다. 업데이트 확인에는 GitHub에 접속합니다.

문제가 생기면 [문제 남기기](https://github.com/HooniKims/lecture_shortcut_mac/issues)에 macOS 버전, 사용한 브라우저, 눌렀던 버튼과 오류 문구를 알려 주세요. 비공개 주소나 개인정보는 지워 주세요.

코드를 직접 수정하거나 빌드하려면 [개발·배포 안내](docs/development.md)를 참고하세요.
