# Cue for macOS

강의 중 앱·창·브라우저 탭을 단축키로 불러오는 macOS 앱입니다. **C / Studio** 어두운 테마와 **B / Paper** 밝은 테마를 Tauri 2와 Swift로 구현했습니다. 현재 버전은 0.1.0 개발 프리뷰입니다.

## 사용 방법

1. Cue를 실행하고 **화면 등록**에서 실행 중인 앱·창·탭을 고릅니다.
2. 이름과 단축키를 지정합니다. 이름의 기본값은 원래 창/탭 제목이며 자유롭게 바꿀 수 있습니다.
3. 환경 설정에서 청중에게 보여줄 모니터를 고릅니다.
4. 등록한 단축키로 화면을 불러옵니다. 그 화면이 이미 맨 앞이면 같은 키로 최소화합니다.
5. 강의별 목록을 프리셋으로 저장하고 **발표자 패널**을 다른 모니터에 띄워둘 수 있습니다.

| 기본 단축키 | 동작 |
| --- | --- |
| `⌘ ⇧ 1`부터 `⌘ ⇧ 9` | 등록 대상별 기본값, 변경 가능 |
| `⌘ ⇧ 0` | 현재 앞에 있는 창/탭 빠른 등록 |
| `⌘ ⇧ Space` | 발표자 패널 표시/숨김 |
| `⌘ ⇧ Return` | 대기 중인 화면 송출 |

환경 설정의 **화면 테마**에서 Studio와 Paper를 선택하고 저장합니다. 메인 화면과 발표자 패널에 함께 적용되며 재시작 후에도 유지됩니다.

환경 설정에서 기능 단축키도 변경합니다. 등록 충돌은 저장 단계에서 안내합니다. 창을 닫아도 메뉴 막대에서 실행되며, 완전히 종료하려면 Cue 메뉴의 종료를 사용합니다.

듀얼 모니터에서는 선택적으로 **대기 모드**를 켜 원래 모니터에서 준비한 뒤 송출합니다. 단일 모니터에서는 대기 모드가 비활성화됩니다. 창 크기는 유지합니다. `재시작 후에도 등록 유지`를 끄면 다음 실행의 현재 목록은 비워지고, 직접 저장한 프리셋과 설정은 유지됩니다.

## 권한과 현재 지원 범위

- 다른 앱의 창 제어에는 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 Cue 허용이 필요합니다. 브라우저 탭에는 **자동화** 권한도 필요합니다.
- Chrome과 Safari의 실제 탭 선택·분리·최소화·복원은 확장 프로그램 없이 네이티브 메뉴로 검증했습니다. Chrome 닫힌 탭은 저장 URL로 다시 엽니다.
- Edge, Brave, Vivaldi, Opera, Arc에는 Chromium 스크립팅 어댑터가 있으나 각 브라우저 실기는 미검증입니다. Firefox 등 스크립팅 미지원 브라우저는 앱/창으로 등록합니다. 모든 브라우저의 탭 제어를 보장하는 버전은 아닙니다.
- 탭 분리 메뉴를 찾을 수 없으면 `브라우저 창 전체 이동`으로 바꾸도록 안내합니다. 한국어·영어 메뉴를 우선 지원합니다.
- 닫힌 앱과 저장된 웹페이지는 다시 열 수 있습니다. 임의 문서 앱의 닫힌 문서까지 복원하지는 않습니다.
- 개발 프리뷰는 Apple Developer ID 서명·공증 없이 로컬 ad-hoc 서명으로 패키징됩니다. 배포용 서명과 공증은 별도 설정이 필요합니다. 앱을 다시 빌드하면 macOS 권한을 다시 허용해야 할 수 있습니다.
- 실제 듀얼 모니터 이동/연결 해제와 Zoom 공유 환경은 사용자의 실기 테스트가 남아 있습니다. 개발 환경은 단일 가상 디스플레이입니다.

## 개발 / 빌드

빌드 환경: macOS 13 이상, Xcode Command Line Tools(Swift), Rust, Node.js, pnpm. 사용자는 이러한 개발 도구를 설치할 필요가 없습니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm test
pnpm build
```

결과는 `src-tauri/target/release/bundle/macos/Cue.app`과 `src-tauri/target/release/bundle/dmg/`에 생성됩니다. 이 저장소의 macOS 네이티브 어댑터를 Windows용으로 교체하면 같은 화면을 재사용할 수 있습니다. Windows 실행파일은 아직 제공하지 않습니다.

설정 파일은 Tauri의 사용자별 config 디렉터리(`dev.cue.desktop/config.json`)에 저장됩니다. 창 제목과 URL이 포함되며 외부 서버로 보내지 않습니다.

## 구현과 검증

- `app/`: 실제 앱 UI. Tauri 명령을 호출합니다.
- `src-tauri/src/`: 전역 단축키, 설정 저장, 프리셋, 창 관리.
- `native/`: Swift macOS 창·탭 제어. [지원 범위와 테스트](native/README.md).
- `design/mockups/`: 이전 디자인 비교용 목업, 실제 앱과 분리되어 있습니다.
- [합의 요구사항](docs/requirements.md), [검증 기록](docs/evidence/implementation-qa.md), [테마·자원 점검](docs/evidence/theme-resource-review.md), [버그·메모리 재검증](docs/evidence/memory-bug-audit.md).

UI는 요청에 따라 ego-browser에서 IPC 테스트 대역을 사용해 검증하고, 설치형 앱은 별도로 실제 Tauri 창과 시스템 단축키로 확인합니다. 브라우저 UI 검증을 OS 제어 검증으로 간주하지 않습니다.
