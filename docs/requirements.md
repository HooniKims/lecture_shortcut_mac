# 강의 화면 전환 앱 — 인터뷰 합의

상태: 기능 인터뷰 완료, C안(Studio) 디자인 확정. 맥 버전부터 구현·검증하고 동일 디자인의 윈도우 버전으로 확장한다. Tauri는 우선 후보이며 기술 검증 전 최종 확정은 아니다.

## 핵심 동작

- 앱, 특정 앱 창, 특정 브라우저 창, 특정 브라우저 탭을 단축키에 연결한다.
- 단축키를 누르면 대상을 맨 앞으로 가져온다.
- 대상이 이미 맨 앞에 있고 해당 탭이 선택되어 있으면 같은 단축키로 최소화한다.
- 가려졌거나 최소화되어 있으면 다시 앞으로 가져온다.
- 닫힌 앱은 실행하고, 닫힌 웹페이지는 저장한 주소로 다시 연다. 작업 중 입력 내용 복원까지 의미하지 않는다.
- 앱의 특정 창이 없을 때 앱 실행만으로 그 문서를 복원할 수 있는지는 별도 구현 검증이 필요하다.

## 모니터와 대기 모드

- Zoom 연수에서는 보통 전체 화면을 공유한다. 지정한 송출 모니터에 실제 대상 창을 옮겨 표시한다. Zoom 공유 대상을 자동으로 바꾸는 기능은 요구하지 않는다.
- 기본은 즉시 송출이다.
- 듀얼 모니터일 때 옵션에서 대기 모드를 켜고 끌 수 있다.
- 대기 모드에서는 원래 모니터에서 준비한 다음 송출 동작으로 청중용 모니터에 옮긴다.
- 싱글 모니터에서는 대기 모드가 없다. 앞으로 가져오기와 최소화만 사용한다.
- 외부 모니터가 분리되면 대기 모드를 해제하고 싱글 모니터 동작으로 전환한다.
- 마지막 화면을 정지 이미지로 유지하는 기능은 제외한다.
- 창 크기는 기존 크기를 유지하며 사용자가 직접 조절한다. 화면 밖으로 벗어난 경우 조작 가능한 위치로 보정한다.

## 등록과 탭

- 기본: 앱 안에서 실행 중인 앱·창·탭 목록을 보고 고른다.
- 보조: 원하는 화면을 직접 띄우고 현재 화면 등록 단축키로 등록한다.
- 등록 이름은 기본적으로 해당 창 제목을 사용한다. 탭을 등록하면 탭 제목을 사용하고, 창 제목이 없는 앱 등록은 앱 이름을 사용한다.
- 등록할 때와 등록한 후 모두 이름을 수정할 수 있다. 사용자 지정 이름은 목록과 발표자 패널에 동일하게 표시한다.
- 표시 이름과 원래 창·탭 제목/대상 식별 정보를 분리해서 저장한다. 표시 이름 수정이 연결 대상을 바꾸지 않는다.
- 탭은 기본적으로 해당 탭만 별도 창으로 분리해서 송출한다.
- 기존 브라우저 창 전체를 이동하는 옵션도 제공한다.
- 크롬이 주 사용 브라우저지만 특정 브라우저에 한정하지 않는 것이 사용자 목표다.
- 별도의 브라우저 확장 프로그램 설치는 허용하지 않는다. 하나의 설치파일로 배포해야 한다. 운영체제 권한 허용은 있을 수 있다.
- 브라우저마다 탭 목록·분리·제어 방법이 달라 모든 브라우저 동일 지원은 검증되지 않았다. 앱/창 지원과 탭 제어 지원을 구분해서 검증하고 한계를 명시한다.

## 단축키와 저장

- 기본 단축키가 있고 사용자가 변경할 수 있다.
- 중복 배정 또는 OS에서 등록 불가능한 조합은 안내한다.
- 재시작 후에도 등록 유지 옵션을 켜고 끌 수 있다. 기본값 켜짐 제안.
- 해당 옵션은 종료 직전 작업 목록 자동 복원을 제어한다. 명시적으로 저장한 프리셋은 계속 남는다.
- 일반 설정과 사용자가 바꾼 기본 기능 단축키는 유지한다.
- 강의별 프리셋을 저장하고 불러올 수 있다.

## 발표자 패널

- 단축키와 등록한 대상 이름을 표시한다.
- 듀얼 모니터에서 발표자 모니터에 계속 띄워둘 수 있다.
- 필요할 때 켜고 끌 수 있다.
- 마우스 드래그로 위치와 모니터를 이동한다.
- 현재 즉시 송출/대기 모드 상태를 확인할 수 있게 한다.

## 디자인 결정 절차

- 사용자는 디자인을 중요하게 생각한다. 기능 구현 전에 디자인 선택을 먼저 진행한다.
- 상용 레퍼런스: Raycast, Things 3, Stream Deck.
- 세 방향의 설정 화면과 발표자 패널 목업을 비교했고, 사용자가 C안(Studio)을 선택했다. 설정 화면과 발표자 패널 모두 C안을 기준으로 구현한다.
- 현재 목업은 design/mockups/index.html. 실제 OS 기능은 연결하지 않은 디자인 프로토타입이다.
- 가칭 CUE는 아직 사용자에게 확정받은 이름이 아니다.
